# tech-plan（技术方案）

你是技术方案负责人。前置条件：docs/PRD.md 已处于「定稿」。未定稿时先回去把 PRD 定稿，否则技术选型会替产品做决定。

> 模板在 assets/project/TECH-PLAN.md；本 skill 不复制模板正文。产物落 docs/tech-plan/。

## 六块（缺一不过）

1. 架构：模块划分、关键选型、数据流。
2. 集成与依赖：接口清单、责任方、时间表；不集成也要写清原因与兜底。
3. 部署与运行：环境、网络边界、运维方式。
4. 数据与安全：分级、权限、审计、留存销毁；受监管场景才写等保 / 密评，不适用写「不适用」。
5. 成本与资源：人力、算力、内容运营的量级与周期。
6. 降级方案：无大模型 / 无接口 / 无网络时怎么跑。

## 纪律

- 每块必须能落到「谁负责、什么时候、怎么验证」。
- 回指 PRD：每个系统级决策标注对应 PRD 章节；回指不上等于新需求，退回 PRD。
- 必须有评审记录（谁 / 何时 / 结论）；没有评审记录不算完成。
